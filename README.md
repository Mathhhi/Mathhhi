## Proyectos destacados

### InMemoriam: sistema de administración de cementerios

Aplicación web lanzada y funcional, con frontend y backend completos.

- Panel administrativo y panel del titular, con inicio de sesión y registro.
- Gestión de bóvedas, contratos, cuotas, difuntos, usuarios, roles y permisos.
- API REST con autenticación JWT, pagos en línea y notificaciones por correo.
- Stack: HTML, CSS, JavaScript, Node.js, Express y MySQL.

[Ver sitio en vivo](https://inmemoriam-ten.vercel.app/)

### Cliente de escritorio/web basado en JavaScript

Cliente para mejorar la experiencia en un juego web, con arquitectura modular.

- Versión portable de escritorio y loader de Tampermonkey para el navegador.
- Servidor en Cloudflare Workers (KV) que autoriza dispositivos mediante códigos de invitación y entrega los scripts cifrados.
- Pipeline de compilación, instalador y distribución de actualizaciones.
- Stack: JavaScript, Electron, Node.js y Cloudflare Workers.

[Descargar versión portable](https://github.com/Mathhhi/uhohidk/releases/latest) · [Instalar loader de Tampermonkey](https://mathias-loader.matiasorteguita123.workers.dev/loader.user.js)
